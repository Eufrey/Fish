# Coastal handmade UI and HUD

Approved direction on 2026-11-16. Figma account s1170356@usls.edu.ph.

Create editable 1280x720 fishing, battle and exploration compositions using the project's seafoam, cream, sand, wood, coral and deep-green palette. Use a wooden circular fishing dial with a green target arc and Space prompt. Keep the existing timing speed and target interval when adapting this presentation to Unity. Battle shows separate current/max HP for player and enemy, team order and Attack/Defend/Special. Shore HUD keeps the center open with objective and contextual E/F prompts. Existing C/N/T/P shortcuts supply navigation.

The selected coastal handmade approach uses soft outlines and restrained depth. The considered bright arcade approach uses stronger saturation and glossy panels. The user chose coastal handmade.

1. Create the school-account Figma Design file and inspect available libraries and fonts.

3. Compose exploration HUD, active fishing and player-turn battle at 1280x720. Include catch success/failure and battle resolving/victory/defeat states.

Readable text and controls, 32px outer clearance, 16px related spacing, explicit outcomes and disabled actions. Use actual configured controls and persistent fish HP. Reference the supplied images for material feel and visual hierarchy. Reuse the current turn-based battle rules when adapting the reference's opposing-player graphics.
